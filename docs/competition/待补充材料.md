# 待补充材料

## 正式提交前优先补齐

1. 将学校、团队名两处xxxxxxxxx替换为实际名称，并同步修改PDF文件名。
2. 72秒对应官方成绩原件、5/5有效状态与各圈时间；保留绑定和环境合规截图。若没有原件，正文继续保留“团队报告”与【待补充验证】，不能改成独立认证结果。
3. 团队自行建模的行业车辆URDF、碰撞／惯量参数和Gazebo世界；建模过程、人员分工、来源说明及核心任务代码。当前官方竞速车模不能作为自主行业建模成果。
4. 行业配送任务仿真截图和演示：装载确认、启动、通行、障碍前停车、停站交接、返回；保存原始任务日志。没有证据就保留【规划实现】，不要删除状态标记。
5. 当前配置的run_report、planned_course_report.json、planned_course.csv、完整控制终端日志与status；如有bag，先结束录制，保存原文件。跨轮材料比较时间戳、参数和reference_sha256。
6. 核对官方允许的里程计适配器／模型／裁判版本，避免把Gazebo全局状态额外用于竞速决策。当前controller只消费公开scan、odom、joint_states及TF，但现有仿真odom来自link_states。

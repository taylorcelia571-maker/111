# 技术事实摘要与全仓审计范围

审计日期：2026年10月14日。分支main；快照`9d7af98d0b3462f6b1afed0b879d7a794ba713cb`。

扫描446个跟踪文件，其中412个可UTF-8读取；14个package.xml、92个Python文件和184处launch节点声明已结构解析。节点声明数包含不同入口和条件分支，不表示单次运行节点数。没有AGENTS.md。

完整清单覆盖README、构建配置、setup.py、launch、YAML、源码、include、URDF／Xacro、RViz、Gazebo世界和地图、测试、Notebook及实验JSON。Python／XML解析无错误。二进制网格和图片检查资源存在；闭源裁判.so不能审计内部算法。

A 软件架构：仿真平台、地图与AMCL／TF、静止整圈规划及连续控制、Ackermann转换、关节执行、独立裁判。

B 节点：当前最快配置核心为map_server、amcl、continuous_race、nav_sim、servo_commands、gazebo_odometry_node、robot_state_publisher和controller_manager加载控制器；sim_referee独立观察。LoopPlanner与PredictiveFollower是类，不是额外节点。

C 接口：scan、odom、joint_states、map、race_path、race_baseline、cmd_vel、ackermann_cmd_stamped、关节command、tf；prepare/start/stop/status为Trigger。move_base action只在旧导航入口使用。

D 输入：当前主控直接使用二维激光、里程计、转向关节和TF；相机与IMU模型存在，未直接接入主控。GPS包存在，不用于室内竞速。

E 链路：传感器／反馈→定位及地图→A*与平滑闭环路线→延迟制动包络→曲率和误差反馈→转角语义Twist→Ackermann→关节控制。

F 算法：现用A*、距离变换、周期高斯平滑、多尺度坐标搜索、循环速度可达性、曲率／误差反馈及Ackermann运动学；Pure Pursuit为可选基线。外部AMCL和关节PID启用。Dijkstra参数、TEB、L1、FTG、沿墙、GMapping、Hector、Cartographer为独立配置或入口；无当前MPC或RRT实现依据。

G 竞速优化：路线与速度评分、弯前制动、转向反馈、静止准备、跨圈连续、地图／激光／时效／偏差保护、批量碰撞计算和后台报告。动态参数通过launch初始化；未证明当前主控支持运动中rosparam热更新。

H 可证技术特点：路线速度联合选择、延迟制动去重复预留、启动和实测转向协同；不宣称原创基础算法。
